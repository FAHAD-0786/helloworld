# 🚀 PlacementPro

A modern placement preparation platform designed to help college students improve their aptitude, coding, communication, and interview skills through an interactive learning experience.

---

## 📖 Overview

PlacementPro is a web-based training platform that provides students with tools to prepare for campus placements. The platform combines aptitude practice, coding challenges, voice analysis, and performance tracking in a single dashboard.

---

## ✨ Features

### 📚 Aptitude Tests
- 200+ Quantitative Aptitude Questions
- Logical Reasoning Practice
- Company-Specific Question Sets
- Instant Score Evaluation

- Built-in Code Editor
- Real-Time Code Execution

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/placementpro.git
```

### Move to Project Directory

```bash
cd placementpro
```

### Install Dependencies

```bash
npm install
```

### Run Frontend

```bash
npm run dev
```

### Run Backend

```bash
pip install -r requirements.txt
python app.py
```
